# NeuroNexus Landing Page

## Project Overview
This repository contains the code for the NeuroNexus landing page, a modern and responsive website built with HTML and CSS.

## Live Demo
Visit the live site: [NeuroNexus Landing Page](https://neuronexus-ibxj.onrender.com/)

## Features
- Responsive design that works on all devices
- Modern and clean user interface
- Fast loading times
- Cross-browser compatibility

## Technologies Used
- HTML5
- CSS3

## Deployment
This site is deployed using Render at [https://neuronexus-ibxj.onrender.com/](https://neuronexus-ibxj.onrender.com/).

The code is also available on GitHub at [https://github.com/ar-codingdecoding/NeuroNexus](https://github.com/ar-codingdecoding/NeuroNexus).

## Installation & Local Development
1. Clone the repository:
   ```
   git clone https://github.com/ar-codingdecoding/NeuroNexus.git
   ```
2. Open the project folder:
   ```
   cd NeuroNexus
   ```
3. Open `index.html` in your browser to view the site locally.
